# 📚 CourseKart Backend

The backend API for **CourseKart**, an online course-selling platform.  
Built with **Node.js, Express, TypeScript, MongoDB, Mongoose, JWT authentication, bcrypt for password hashing, and Zod for validation**.

---

## 🚀 Features

- 🔑 **User Authentication**
  - Signup / Login with JWT
  - Passwords hashed with bcrypt
- 🛒 **Course Management**
  - Create, update, delete, and fetch courses
  - Enroll in courses
- 👨‍🎓 **User Dashboard**
  - View purchased/enrolled courses
- ✅ **Validation**
  - Input validation with Zod
- 🔐 **Authorization**
  - Role-based access (User / Admin)

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js, TypeScript
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT, bcrypt
- **Validation:** Zod
- **Environment:** dotenv
